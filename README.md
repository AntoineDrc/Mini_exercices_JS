
# Projet d'exercices JavaScript, HTML, CSS

Ce projet regroupe plusieurs exercices de programmation utilisant HTML, CSS et JavaScript. Chaque exercice met en œuvre des fonctionnalités interactives différentes et vise à améliorer les compétences en développement front-end. Voici une description des technologies et fonctionnalités pour chaque exercice :

## Technologies utilisées
- **HTML5** : Structure de base des pages web et des formulaires interactifs.
- **CSS3** : Mise en forme des éléments, animations et transitions visuelles.
- **JavaScript** : Gestion des événements, manipulation du DOM et génération dynamique de contenu.

## Fonctionnalités principales
### Exercice 1 : Ajouter un élément à une liste via un formulaire
- **Technologies** : HTML, CSS, JavaScript
- **Description** : Cet exercice permet à l'utilisateur d'ajouter un élément à une liste en utilisant un formulaire HTML. L'élément est ajouté dynamiquement à la liste après soumission du formulaire sans rechargement de la page grâce à la gestion des événements JavaScript.
- **Objectif** : Manipuler le DOM et gérer les événements de soumission de formulaires.

### Exercice 2 : Changer la couleur de fond aléatoirement
- **Technologies** : HTML, CSS, JavaScript
- **Description** : Un bouton permet de changer aléatoirement la couleur de fond de la page principale à chaque clic. L'exercice utilise des fonctions JavaScript pour générer des couleurs RGB aléatoires et appliquer ces valeurs au style CSS de l'élément ciblé.
- **Objectif** : Manipuler le style CSS via JavaScript et utiliser des fonctions pour créer des valeurs dynamiques.

### Exercice 3 : Changer la couleur d’une boîte au survol et au clic
- **Technologies** : HTML, CSS, JavaScript
- **Description** : Des boîtes changent de couleur lorsque l'utilisateur passe la souris dessus et au clic. Le fond de la page change également pour refléter la couleur de la boîte cliquée. La gestion des événements de survol, de clic et la manipulation du DOM sont utilisées.
- **Objectif** : Gérer plusieurs événements sur des éléments HTML et appliquer des animations via CSS.

### Exercice 4 : Cartes animées de personnages (avec son)
- **Technologies** : HTML, CSS, JavaScript, Médias (images, son)
- **Description** : Des cartes de personnages de *Dragon Ball* qui se retournent lorsque l'utilisateur clique dessus, avec un effet sonore associé. L'arrière des cartes révèle des informations supplémentaires sur chaque personnage.
- **Objectif** : Utiliser des animations en 3D (rotation des cartes), gérer les événements de clic, et intégrer des médias (images, sons).

### Exercice 5 : Générateur de créatures fantastiques
- **Technologies** : HTML, CSS, JavaScript
- **Description** : Un générateur de créatures fantastiques permet à l'utilisateur de sélectionner entre différentes créatures (dragon, elfe, troll) en cliquant sur des boutons. Chaque créature est affichée avec une image et une description correspondante.
- **Objectif** : Utiliser JavaScript pour afficher dynamiquement des informations basées sur les interactions de l'utilisateur.

### Exercice 6 : Générateur de nombres aléatoires
- **Technologies** : HTML, CSS, JavaScript
- **Description** : Ce générateur de nombres aléatoires affiche la liste des nombres générés ainsi que la moyenne des valeurs. La liste des nombres s'allonge à chaque nouveau clic.
- **Objectif** : Manipuler des tableaux et effectuer des calculs simples sur des données en temps réel avec JavaScript.

### Exercice 7 : Carte interactive de régions fictives
- **Technologies** : HTML, CSS, JavaScript, Médias (images)
- **Description** : Une carte interactive avec plusieurs régions fictives (Forêt des Elfes, Mine des Nains, Volcan des Dragons, etc.). En cliquant sur une région, des informations sur celle-ci s'affichent.
- **Objectif** : Utiliser des données personnalisées associées à des éléments HTML et gérer des événements de clic pour afficher dynamiquement des informations.

## Structure du projet
- **HTML** : Chaque exercice a son propre fichier HTML définissant la structure de la page.
- **CSS** : Un fichier CSS commun définit le style visuel et les animations.
- **JavaScript** : Chaque exercice utilise des fichiers JavaScript séparés pour la logique fonctionnelle, incluant la gestion des événements et la manipulation du DOM.
